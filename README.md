# Samrat Chauhan - Portfolio

A modern developer portfolio showcasing my projects, skills, and experience in Full Stack Development, AI Engineering, and Automation.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Features

- Responsive modern UI
- Interactive project showcase
- Project deep-dive modals
- Skills & technology section
- Engineering journey
- GitHub and contact links
- Smooth animations

## Featured Projects

- GitStream
- JuryAI
- JobHunter
- SalesBot.AI
- Leet'O Tracker AI
- PickMyPhone AI
- SPECSMASTER

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

Build for production:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
